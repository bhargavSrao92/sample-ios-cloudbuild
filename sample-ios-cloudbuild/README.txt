Sample iOS project scaffold for Google Cloud Build IPA generation.

Contents:
- SwiftUI sample app source
- cloudbuild.yaml
- ExportOptions.plist

Steps:
1. Open Xcode
2. Create project named MySampleApp
3. Replace generated ContentView.swift and MySampleApp.swift with provided files
4. Commit to GitHub
5. Connect repo to Google Cloud Build
6. Configure Apple signing certificates/profiles
7. Trigger build -> IPA artifact generated
